Sync with GitHub

Syncing saves your articles and watchlist to data/saved.json in your repo. That lets every device see them, and lets the updater fetch article titles, follow-up coverage and ticker news. The token stays in this browser only.

Create a fine-grained token on GitHub (Settings, Developer settings, Personal access tokens, Fine-grained). Give it access to this one repository with Contents: read and write and Actions: read and write.
